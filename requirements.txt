# System-dependency notes (see Dockerfile) - these Python packages shell
# out to system binaries that must be installed alongside them:
# - ocrmypdf (OCR, apps/pdf_ocr) needs `tesseract` (apt: tesseract-ocr
#   plus per-language tesseract-ocr-<lang> packs) and reuses `gs` below.
# - PDF -> PDF/A (apps/pdf_convert/converters/pdf_to_pdfa.py) shells out
#   to `gs` (apt: ghostscript).
# - Word/Excel/PowerPoint -> PDF (apps/pdf_convert/converters/office_to_pdf.py)
#   shells out to `soffice` (apt: libreoffice-writer/-calc/-impress).
# - weasyprint (HTML -> PDF) loads Pango/cairo via cffi at import time
#   (apt: libpango-1.0-0, libpangocairo-1.0-0, libcairo2, libgdk-pixbuf-2.0-0).
